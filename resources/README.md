Concepto C: cilindro de base de datos conectado a una tabla, en azul y celeste sobre una base azul marino.

- `icon-source.png`: original generado con la herramienta integrada imagegen.

La configuración de iconos para empaquetado no genera ni publica instaladores.

## Prompt del original

Extract and faithfully recreate ONLY concept C, the RIGHTMOST large app icon from this reference branding sheet. Final standalone square Visual BD app icon. Dark navy rounded square tile, bright cobalt blue database cylinder on left, with layered curved bands including a light blue band. White circular port near cylinder lower-right connects with a short white orthogonal line to a small pale-blue table card on right with two blue slots. Match concept C closely; do not use the table diagram A or the V symbol B. Flat clean precise geometry with subtle original shading, strong small-size readability. No text, no letters, no comparison sheet, no captions, no shadows outside tile. Centered icon fills about 94% of square canvas; genuinely transparent outside rounded corners. High resolution 1024x1024.
